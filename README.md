# Course_website

My learning notes — a chapter for every topic I pick up.

- **Live:** deployed on Vercel
- **Stack:** Next.js + Tailwind, content is plain Markdown in `content/`
- **Adding notes:** drop a `.md` file in `content/<chapter>/` — nav, search and
  prev/next update themselves. See [CLAUDE.md](CLAUDE.md) for the full guide.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```
